# Lightbox

Lightbox is a private gallery for Android. It shows every photo and video on the phone, finds them by what
is in them and where they were taken, edits and tidies them, and takes the hidden information out before
you share. It has no adverts, no accounts, no paid version and no internet access.

- Website: https://customgpter.github.io/lightbox/
- Latest app file: https://github.com/CustomGPTer/lightbox/releases/latest
- Privacy: https://customgpter.github.io/lightbox/privacy.html

This repository holds the website and the released app files. The app's source code is not published here.
